# nu-shinkan project

## ワークスペースのセットアップ

[workspaceリポジトリ](https://github.com/nu-shinkan-project/workspace)が提供するスクリプトコマンドを実行することで，
自動で推奨構成のワークスペースがセットアップされます．

## リポジトリの説明

- **[nu-shinkan](https://github.com/nu-shinkan-project/nu-shinkan):** 
  プロダクトコードの管理開発を担うメインリポジトリです
- **[context](https://github.com/nu-shinkan-project/context):** 
  AI Agentと共有するコンテキストなどをメインコードとは別のライフサイクルで管理します．
